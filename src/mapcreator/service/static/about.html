mapcreator

About, data sources and privacy.

What this is

mapcreator turns a stretch of real road into a track for Assetto Corsa on PC. You pick the road on the map; a build server snaps it to OpenStreetMap, lays it over a terrain model, adds verges, trees, buildings, timing gates and an AI line, and packs it as a zip you can install with Content Manager or by hand. It's free, and it uses open data only.

Roads in Tasmania use the state's 2 metre terrain model, tree heights and building outlines. Elsewhere in Australia, a road uses Geoscience Australia's 5 metre LiDAR model where it covers the whole road, then (in Victoria) the state's 10 metre model, and the 30 metre national model otherwise, so roads away from towns come out smoother than the real thing.

Where the data comes from

  • Roads: © OpenStreetMap contributors, under the Open Database Licence (ODbL).
  • Tasmania: the 2 metre DEM, Tree Canopy Height and 2D Building Polygons from theLIST, © State of Tasmania, CC BY 3.0 AU.
  • Elevation elsewhere: Geoscience Australia's DEM of Australia derived from LiDAR 5 Metre Grid and 1 second SRTM DEM-S, © Commonwealth of Australia, CC BY 4.0; in Victoria, where GA's 5 m doesn't reach, Vicmap Elevation DEM 10m, © The State of Victoria, CC BY 4.0.
  • Trees elsewhere: ESA WorldCover 10 m 2021, © ESA WorldCover project 2021, containing modified Copernicus Sentinel data, CC BY 4.0.
  • The map on this page: OpenFreeMap, © OpenMapTiles, and theLIST's Topographic Basemap.

Every track carries an ATTRIBUTION.txt naming exactly the sources it was built from. It also carries the road's centreline, with its heights and widths, as centreline.geojson under the ODbL. If you share a track, keep both files with it.

No Google, Esri, Bing or Mapbox data is used anywhere in a build.

Using the tracks

Install with the Content Manager link on your job's page, or unzip the download into assettocorsa/content/tracks. Each road can come with a layout for each direction. Trees are 3D models drawn by Custom Shaders Patch (0.1.79 or later); without it, a track has no trees. The tracks are generated, not hand-made: expect the odd rough edge, especially where the map data is thin.

Privacy

There are no accounts, no analytics and no advertising, and mapcreator sets no cookies. Here is everything it keeps:

  • Your job: the points you placed, the options you chose and the track name you typed. It's deleted 30 days after the build finishes. The finished zip is deleted from the download server a few days after that.
  • A scrambled form of your internet address, used only to limit each person to five tracks a day. It's a keyed hash, not the address itself, and it's blanked after two days.
  • Route previews are limited per address per minute. That count is held in memory for a minute and never written down.

The server keeps no access log: it doesn't record your address or which pages you load. It logs each job's id as it's queued, built and finished.

Anyone with your job's link can see its status and download its track. If someone else asks for exactly the same road with the same options, they're given the same job rather than a second build, so they see the track name you typed.

Three other services see your request when you use the page:

  • Cloudflare carries the site and runs the Turnstile check that keeps scripts from filling the queue.
  • OpenFreeMap serves the map tiles.
  • theLIST serves the topographic map, if you switch it on.

Those services receive your address the way any website you load does.
